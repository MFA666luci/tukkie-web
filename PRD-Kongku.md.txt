## 1. Product Overview

### 1.1 Deskripsi Produk

Tukkie merupakan brand toko online yang berfokus pada penjualan makanan tradisional Indonesia, dengan produk utama berupa Getuk Singkong Goreng.

Website Tukkie dirancang sebagai landing page toko online yang menggabungkan identitas makanan tradisional dengan desain modern, menarik, dan mudah digunakan.

Pengunjung dapat melihat informasi brand, mengenal produk, melihat galeri foto, mengetahui harga, dan melakukan pemesanan secara langsung melalui WhatsApp.

Website tidak menyediakan sistem checkout atau pembayaran internal. Seluruh proses pemesanan dilakukan melalui WhatsApp.

### 1.2 Visi Produk

Membangun identitas digital Tukkie sebagai brand makanan tradisional yang modern, menarik, mudah dikenali, dan mudah dijangkau oleh pelanggan melalui platform online.

### 1.3 Tujuan Website

1. Memperkenalkan brand Tukkie kepada calon pelanggan.
2. Menampilkan produk Getuk Singkong Goreng secara menarik.
3. Menyediakan informasi produk dan harga secara jelas.
4. Mempermudah pelanggan melakukan pemesanan.
5. Membangun identitas visual brand yang konsisten.
6. Mengarahkan pengunjung untuk melakukan transaksi melalui WhatsApp.

## 6. WhatsApp Ordering System

**Prioritas: Critical**

WhatsApp merupakan satu-satunya saluran pemesanan produk Tukkie.

### 6.1 Konsep Pemesanan

Pengunjung dapat melakukan pemesanan tanpa harus membuat akun atau menggunakan checkout internal.

### 6.2 Alur Pemesanan

1. Pengunjung membuka website Tukkie.
2. Pengunjung melihat informasi produk.
3. Pengunjung menekan tombol Pesan Sekarang.
4. Website membuka WhatsApp.
5. Pesan otomatis ditampilkan.
6. Pengunjung mengirim pesan kepada penjual.
7. Penjual melanjutkan proses pemesanan.

### 6.3 Contoh Pesan Otomatis

Halo Tukkie! Saya ingin memesan produk:

- Produk: Getuk Singkong Goreng
- Harga: Rp5.000/porsi
- Jumlah:

Mohon informasi lebih lanjut mengenai pemesanan. Terima kasih!

### 6.4 Implementasi Teknis

```typescript
const phoneNumber = "628XXXXXXXXXX";

const message = `
Halo Tukkie! Saya ingin memesan:

Produk: Getuk Singkong Goreng
Harga: Rp5.000/porsi

Mohon informasi lebih lanjut.
`;

const whatsappURL =
  `https://wa.me/${phoneNumber}?text=${encodeURIComponent(message)}`;

window.open(whatsappURL, "_blank");
```

**Catatan:** Nomor WhatsApp harus diganti dengan nomor resmi penjual menggunakan format internasional tanpa tanda `+`, spasi, atau angka nol di awal.

## 8. Technical Requirements

### 8.1 Tech Stack

| Technology | Fungsi |
|---|---|
| Next.js | Framework utama frontend dan routing. |
| React | Komponen dan interaktivitas UI. |
| TypeScript | Type safety dan struktur kode. |
| Tailwind CSS | Styling dan responsive layout. |
| Lucide React | Ikon navigasi dan elemen UI. |
| Vercel | Deployment dan hosting. |

### 8.2 Architecture

Website menggunakan arsitektur frontend sederhana berbasis Next.js App Router.

- Next.js App Router untuk routing.
- React Components untuk membangun UI.
- Tailwind CSS untuk styling.
- Client-side interaction untuk navigasi dan interaksi UI.
- WhatsApp Click-to-Chat API untuk pemesanan.
- Static rendering untuk konten landing page.

**Database:** Tidak diperlukan untuk MVP karena website belum memiliki sistem akun, checkout, maupun penyimpanan transaksi.
